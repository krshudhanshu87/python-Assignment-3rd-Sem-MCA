# Snake Game using Python

A simple Snake Game developed using Python and Tkinter GUI library.

## Features

- Snake movement using arrow keys
- Random food generation
- Score tracking system
- Collision detection
- Dynamic difficulty
- Snake speed increases as score increases
- Game Over screen with final score

## Technologies Used

- Python 3
- Tkinter
- Random Module


## Controls

| Key | Action |
|------|---------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |

## Game Rules

1. Eat food to increase score.
2. Snake grows after eating food.
3. Speed increases with score.
4. Avoid hitting walls.
5. Avoid colliding with your own body.
